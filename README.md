# Nómada Store

Tienda de camping y aventura construida con React, Vite y React Router.

## Desarrollo

Instalá dependencias con `npm install` y ejecutá `npm run dev` para iniciar el servidor local.

## Validación

- `npm run lint`: revisa el código con ESLint.
- `npm run build`: genera la versión de producción en `dist/`.

El catálogo se sirve desde `public/productos.json` y el estado del carrito se comparte mediante Context API.
